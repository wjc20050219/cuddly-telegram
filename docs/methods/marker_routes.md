# 候选标记体系（四条路线）

> **TASK-007 输出** · 建立日期：2026-09-16
> 项目：RiceVar-ID（基于 ulcWGS 的水稻品种数字身份证系统）
> 上游依据：`paper_workflow.md`（TASK-005）、`wheat_to_rice_migration.md`（TASK-006）

---

## 0. 本文档的定位

**任务清单要求**：至少建立四条候选路线 —— A SNP / B k-mer / C CNV / D SV·PAV。

**本文档在任务清单基础上补充了三件事**：

1. **统一约束**——四条路线都必须在 **ulcWGS（超低深度，0.01×–1.00×）** 条件下评价，这是本项目与普通品种鉴定研究的根本区别；
2. **公平比较框架**——规定四条路线必须用**同一批样本、同一深度梯度、同一评价指标**比较，否则结论无意义；
3. **诚实的先验判断**——对每条路线在低深度下的**预期表现与风险**作出标注，并**明确哪些是假设、哪些是已知**，避免预设结论。

## 1. 本项目的四条硬约束

所有路线设计都必须满足这四条，否则方案不成立：

| # | 约束 | 含义 | 影响 |
| --- | --- | --- | --- |
| **C1** | **必须在 ulcWGS 下工作** | 目标测序深度 **0.01×–1.00×**（最低可能到 0.01×） | 决定性的筛选条件。任何"只在 10× 以上成立"的标记类型都不满足项目目标 |
| **C2** | **不做新湿实验** | 全部基于公开数据 | 标记必须能从公共数据集中复用，不能依赖自行设计的引物/探针 |
| **C3** | **只传输特征矩阵** | 原始 FASTQ/BAM 不出服务器 | 标记的中间产物必须是**可压缩的特征矩阵**，不能是原始比对文件 |
| **C4** | **不预设最优标记类型** | 四路线并行实测 | 禁止在实验前断言 CNV（或任何一路）更优。论文的成功前提（六倍体超大 CNV）在水稻不成立（见 TASK-006 第 3.3 节） |

> **C1 是整个项目最锋利的约束**。它把"品种鉴定"这个常规问题变成了一个**信息论问题**：
> 在只有 ~0.05× 覆盖度（约 1 GB 数据）时，基因组上还有多少**可判别信号**？
> 不同标记类型对低深度的耐受性差异极大，这正是本项目要测的核心科学问题。

## 2. 路线 A：SNP

### 2.1 流程（任务清单指定）

```
WGS → Mapping → SNP calling → High-quality SNP → Discriminative SNP → Fingerprint
```

### 2.2 具体实现

| 环节 | 方法 | 工具（本项目已装） | 状态 |
| --- | --- | --- | --- |
| Mapping | 比对到 IRGSP-1.0 | `bwa-mem2 2.3` → CRAM | ✅ 已就位 |
| SNP calling | 多样本联合分型 | `bcftools 1.24`（`mpileup`+`call`） | ✅ 已就位 |
| 高质量 SNP | 按 QUAL / DP / missing rate / 双等位 过滤 | `bcftools filter` / `vcftools` | 🔧 阈值待定 |
| 判别性 SNP | 高 MAF + 高品种间信息量 | 自研脚本（`src/`） | ⬜ 待实现 |
| Fingerprint | 每位点取基因型（0/1/2 或 0/1） | 自研脚本 | ⬜ 待实现 |

### 2.3 关键参数（待定项）

| 参数 | 待定值 | 决定方式 |
| --- | --- | --- |
| 最低 QUAL | — | 用低深度数据扫 |
| 最低 DP | — | **必须允许 DP 低至 1–2**（0.05× 下多数位点覆盖为 0） |
| missing rate 上限 | — | 直接影响可用位点数 |
| MAF 下限 | — | 与判别力权衡 |
| 标记数 | — | 需做饱和曲线 |

### 2.4 ulcWGS 下的预期与风险

**预期优势**：
- 是**唯一有大量水稻先例**的路线（3K RGP 等大规模重测序研究都以 SNP 为主）；
- 单位点信息明确，缺失可编码，与 Jaccard 相似度框架兼容；
- 计算成本最低（`bcftools` 占实测 CPU 的 15.8%，见 `benchmark_results.md`）。

**主要风险（必须实测，不能假定）**：
- ⚠️ **低覆盖下的基因型缺失是结构性的**：0.05× ≈ 每 100 bp 约 0.05 条读段，
  绝大多数位点**根本没有覆盖**。可用位点数可能比高深度下降 2–3 个数量级；
- ⚠️ **单读段支撑的基因型错误率高**：DP=1 时的基因型判读接近随机；
- ⚠️ **ascertainment bias**：若用高深度数据选 SNP 再拿到低深度用，
  被选中的位点恰恰是"高深度下才可靠"的位点，会产生系统性乐观偏差。
  → **必须用低深度数据本身重选 SNP**（与 TASK-006 第 4 节第 3 条同一逻辑）。

> **论文对照**：Niu et al. 用 GATK 检测 SNP 作**对照**，但未给出低深度下的 SNP recall 细节。
> 本项目需要补这一块——这正是 TASK-051/052 的增量。

## 3. 路线 B：k-mer

### 3.1 流程（任务清单指定）

```
FASTQ → K-mer counting → Unique k-mer → Variety-specific k-mer → Fingerprint
```

### 3.2 具体实现

| 环节 | 方法 | 工具（本项目已装） | 状态 |
| --- | --- | --- | --- |
| K-mer counting | 计数所有 k-mer 频次 | `KMC 3.2.4` 或 `jellyfish 2.3.1`（CLI） | ✅ 已就位 |
| Unique k-mer | 剔除高频（重复序列）与极低频（测序错误） | KMC 的 `-ci` / `-cx` | 🔧 阈值待定 |
| Variety-specific k-mer | **品种间差异 k-mer** | 自研脚本（需多样本交集/差集） | ⬜ 待实现 |
| Fingerprint | 每位点 presence/absence → 0/1 | 自研脚本 | ⬜ 待实现 |

### 3.3 k 值测试计划（任务清单指定）

**必须测试 k = 21 / 25 / 31 / 35 / 41 / 51**（共 6 个值）

| k | 特异性 | 对测序错误的敏感性 | 在 0.05× 下的可获得性 |
| --- | --- | --- | --- |
| 21 | 低 | 低 | 高（短 k-mer 更容易被单个读段覆盖） |
| 31 | 中 | 中 | 中 |
| 51 | 高 | 高 | **低**（长 k-mer 要求更长/更多读段支撑） |

> **核心张力**：k 越大，品种间特异性越强，但**在低深度下越难被观测到**。
> 存在一个最优 k，**必须实测，不能预设**。这 6 个值的曲线本身就是本路线的重要产出。

### 3.4 ulcWGS 下的预期与风险

**预期优势**：
- ★ **不需要参考基因组、不需要比对**——直接对 FASTQ 计数。
  这带来**架构上的根本差异**：计算量小、无参考依赖，且**天然规避比对步骤**。
  回顾 `benchmark_results.md`：**比对占实测 CPU 的 69.8%**，
  若 k-mer 路线成立，可以**直接省掉这 69.8%**——这是极大的成本优势；
- 适合"上传—比对—返回"的平台模式（用户只需上传 FASTQ）。

**主要风险**：
- ⚠️ **低深度下的 k-mer 缺失**：0.05× 时大部分基因组区域无读段，
  品种特异 k-mer 的观测概率直接由覆盖度决定，可能大量漏检；
- ⚠️ **测序错误的假 k-mer**：低深度下每个错误读段产生的假 k-mer 相对占比升高，
  过滤阈值必须重定；
- ⚠️ **重复序列导致的假阳性**：水稻基因组重复比例高，需谨慎去重；
- ⚠️ **指纹长度可能极长**（数十万至数百万 k-mer）→ 存储与相似度计算成本需评估（约束 C3）。

## 4. 路线 C：CNV

### 4.1 流程（任务清单指定）

```
WGS → Read depth → CNV → CNV Block → Stable marker → Binary fingerprint
```

### 4.2 具体实现

| 环节 | 方法 | 工具（本项目已装） | 状态 |
| --- | --- | --- | --- |
| Read depth | 窗口化深度统计 | `mosdepth 0.3.14` / `bedtools 2.31.1` | ✅ 已就位 |
| 归一化 | 窗口深度 ÷ 全基因组众数 | `awk` / R | ✅ 方法已定（TASK-006 判定可迁移） |
| CNV 判定 | 偏离阈值（论文 0.5 / 1.5） | 自研脚本 | 🔧 **阈值必须重算** |
| CNV Block | 连续同类窗口合并 + HMM 平滑 | `hmmlearn 0.3.3` | ✅ 已装 |
| Stable marker | **ulcWGS 反筛**（论文核心创新） | `samtools view -s` 模拟 + 自研脚本 | ✅ 方法可迁移 |
| Fingerprint | 0/1 二进制（present/absent） | 自研脚本 | ✅ 方法可迁移 |

### 4.3 关键参数（**全部必须重定，禁止照搬小麦**）

| 参数 | 小麦论文值 | 水稻必须做什么 | 依据 |
| --- | --- | --- | --- |
| **窗口大小** | 100 Kb | **在 1 / 5 / 10 / 50 / 100 kb 间比较选优** | 水稻平均 CNV ≈ 7.5 Kb，100 Kb 窗口大 13 倍 |
| **长度过滤** | ≥100 Kb | 按水稻 CNV 长度分布重定 | 水稻 CNV 总长仅 ~142 Kb |
| 缺失判定 | <0.5 | 重验 | 尺度变化后信噪比不同 |
| 重复判定 | >1.5 | 重验 | 同上 |
| HMM 参数 | n=3, iter=60, tol=1e-3 | 作**初值**，需重验 | 水稻状态切换更频繁，有过度平滑风险 |
| 连锁合并间距 | ≤5 Mb | 按水稻连锁不平衡衰减重定 | 水稻多条染色体短于 30 Mb |
| **判定阈值** | **85%** | ❌ **绝对禁止照搬**，用水稻数据重算 | TASK-053 |

### 4.4 ulcWGS 下的预期与风险

**预期优势**：
- ★ **read depth 是低深度下最稳健的信号**——它不要求覆盖到特定碱基，
  只要求窗口内**平均**有读段。0.05× 下 100 kb 窗口仍有 ~18,750 bp 覆盖，足以估计相对深度；
- ★ **论文已验证到 0.01× 仍可用**（0.05× 平均 recall 99.3%）——虽是小麦，但机制上支持低深度；
- 该方法本身就是"用低深度反筛 marker"的产物，**与项目目标天然契合**。

**主要风险**：
- ⚠️ **尺度不匹配是最大风险**：水稻 CNV 只有小麦的 1/1000–1/10000，
  信号绝对幅度小得多，可能在噪声里淹掉（此风险与窗口选择强耦合，是 TASK-038 的核心问题）；
- ⚠️ **二倍体缺乏小麦的亚基因组交换机制**（TASK-006 第 3.3 节），
  产出 CNV 的生物学基础不同，**可判别 CNV 位点数可能远低于小麦**；
- ⚠️ **GC 偏倚与可重复性**：水稻基因组的 GC 分布不均，需做 GC 校正；
- ⚠️ 必须**单独评估**"到底有多少"水稻 CNV 是低深度可稳定检测的——
  这是 TASK-038/049 要回答的，**不能假定**。

> **⚠️ 再次强调**：本路线是**参考论文的路线**，因此最容易产生"照搬"冲动。
> 但 TASK-006 已论证其成功前提在水稻不成立。**在实测数据出来前，不得假定 CNV 最优。**

## 5. 路线 D：SV / PAV

### 5.1 分析对象（任务清单指定）

- deletion（缺失）
- insertion（插入）
- inversion（倒位）
- translocation（易位）
- presence/absence variation（PAV，存在/缺失变异）

### 5.2 与路线 C 的关系（必须先厘清）

**deletion / duplication 在两条路线里是重叠的**，区别在检测机制：

| | 路线 C（CNV） | 路线 D（SV） |
| --- | --- | --- |
| **检测信号** | 窗口化 **覆盖深度**（间接） | **断点证据**：split reads + discordant pairs（直接） |
| **分辨率** | 受窗口大小限制（kb 级） | 断点级（bp 级） |
| **低深度可行性** | ✅ 较好（深度是聚合量） | ❌ **很困难** |
| **输出** | 区间 + 相对拷贝数 | 精确断点 + 类型 |

> **本路线在 ulcWGS 下的可行性是四条路线中最低的，必须重点实测。**
> 原因：SV 检测依赖**跨越断点的 split reads** 或**方向异常的双端读段对**——
> 在 0.05× 下，一个 350 bp 的 SV 断点可能**一条读段都没覆盖**。
> 这是**定性困难**，不是调参能解决的。

### 5.3 具体实现

| 对象 | 方法 | 工具 | 状态 |
| --- | --- | --- | --- |
| Deletion | 覆盖深度 + split read | `mosdepth` + 自研 / `delly`（未装） | ⬜ 待评估 |
| Insertion | split read + assembly | `minimap2 2.31`（长读）/ `delly` | ⬜ 待评估 |
| Inversion | discordant pair 方向 | `delly` / `manta`（未装） | ⬜ 待评估 |
| Translocation | 跨染色体 discordant pair | `delly` / `manta` | ⬜ 待评估 |
| PAV | **泛基因组比对** | `minimap2` + 泛基因组 | ⬜ 待评估 |

> **工具缺口**：标准 SV 工具（`delly` / `manta` / `smrtlink`）**尚未安装**。
> 若本路线值得推进，需在 TASK-038 前补充安装（评估 CPU/内存需求）。

### 5.4 ⚠️ 一个更现实的替代形态

鉴于断点级 SV 检测在 ulcWGS 下困难，**本路线应以"PAV 优先"的形态进入比较**：

- **PAV via 泛基因组**：水稻已有公开泛基因组（如 3K RGP 派生的 PAV 矩阵），
  可直接复用为**先验参考集**，再用低深度数据做 presence/absence 判定；
- 这与路线 C 的"反筛"逻辑一致，且**不需要从零检测断点**；
- 具体可行性需在 TASK-037/038 用实测数据判断。

## 6. 统一比较框架（公平比较的前提）

四条路线若不在**同一条件下**比较，结论无效。规定如下：

### 6.1 比较条件（必须严格一致）

| 维度 | 规定 |
| --- | --- |
| **样本** | 同一批样本（Pilot 20–50 份 → 正式面板） |
| **深度梯度** | 同一套：**0.01 / 0.02 / 0.05 / 0.10 / 0.20 / 0.50 / 1.00×** |
| **重复数** | 每档 **≥5（理想 10）** 次独立下采样 |
| **参考基因组** | IRGSP-1.0（路线 B 不需要） |
| **相似度** | 统一用 **Jaccard**（`M_share/(M_s1+M_s2−M_share)`） |
| **阈值** | 各路线**分别**用 ROC 选定，再比较 |
| **测试集** | 独立测试集从开始就冻结（TASK-016） |

### 6.2 评价指标（必须全部报告）

| 指标 | 用途 |
| --- | --- |
| **ROC 曲线 + AUC** | 主指标。**论文全文没有 ROC/AUC，这是本项目的核心增量** |
| Precision / Recall / F1 | 在选定阈值下 |
| FPR / FNR | 品种鉴定中两类错误的后果不同 |
| **Coverage–Recall 曲线** | 确定最低有效深度（本项目核心产出） |
| 标记数 vs 准确率（饱和曲线） | 判断标记是否足够 |
| **计算成本**（核时/样本） | 已实测（`benchmark_results.md`） |
| **存储成本**（GB/样本） | 本项目真正的瓶颈是磁盘 |
| 指纹矩阵大小 | 约束 C3 |

### 6.3 比较的公平性红线

- ❌ **不允许**对某条路线单独放宽深度范围或样本量；
- ❌ **不允许**用各路线自己的最优深度去和别人的最差深度比；
- ❌ **不允许**在看过结果后才决定测试集划分；
- ✅ **必须**同时报告"准确率"和"成本"——因为本项目受磁盘约束。

- **CNV 的成功前提在小麦是六倍体亚基因组交换，水稻不具备**；
- 小麦的窗口/长度/阈值参数**一个都不能照搬**。
