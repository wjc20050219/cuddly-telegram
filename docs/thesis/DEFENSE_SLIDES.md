## 3 研究背景：为什么做品种识别
- 种子真实性鉴定的生产需求
- 现有分子标记方法的通量与成本限制
- 一句话点出矛盾：**要准确就要深度，要便宜就要降深度**

## 4 问题定义
- 目标：给定一个超低深度样本，能否判断它是哪个品种
- 两类任务要分清：
  - **闭集识别**：候选品种已知
  - **开放集识别**：候选里可能根本没有这个品种 → 必须能拒识
- 明确本文两个任务都做，且用不同数据集评估

## 5 技术路线总览（一张流程图）
```
公共 WGS 数据
   ↓ 质控 / 比对
Pilot 高深度联合 calling
   ↓ SNP 质控 + 信息量排序
冻结 500 / 1000 / 2000 位点
   ↓                        ↘
六梯度降采样            固定位点判型 → 低深度指纹
   ↓
IBS 相似度 → Top-1/Top-5（闭集，技术重复）
零重叠独立面板 → 拒识评估（开放集）
```

## 8 关键方法一：为什么必须联合 calling
- 反面做法：合并单样本变异 VCF、把缺失当 `0/0`
  → **系统性高估一致性**
- 本文做法：联合 calling 或固定位点判型
- 这一页要讲清"我们避开了什么坑"

## 9 关键方法二：位点冻结与缺失处理
- 位点集合只由 Pilot 决定，独立面板不参与筛选与调阈值
- 缺失记为 `-1`，**不做插补**（避免用模型结果冒充观测结果）
- 报告相似度时**同时报告比较位点数与比较率**

## 10 关键方法三：识别与拒识
- IBS 为主，Hamming/Jaccard 对照
- 比较位点少于阈值（默认 50）→ 判为无法识别
- 拒识阈值在 Pilot 内确定后冻结

## 11 评估指标
- marker recall / 基因型一致率 / Top-1 / Top-5 / 拒识率
- **评估边界声明**（重要，建议单独强调）：
  - 深度曲线 = 同批样本降采样 = **技术重复**，只支撑闭集结论
  - 独立零重叠面板只支撑**开放集拒识**

## 预设提问与准备

答辩老师很可能问的问题，提前准备答案：

| 问题 | 应答要点 |
| --- | --- |
| 你的低深度结果是不是"模拟"的？ | 是真实公共数据的**降采样技术重复**，不是纯模拟；局限已在 4.3 说明 |
| 为什么不直接测低深度真实样本？ | 成本与批次不可控；降采样能精确控制深度变量，是方法学研究的常规做法 |
| 0.02× 还有意义吗？ | 用 recall 与比较位点数说明可用信息量，并明确给出不可用下限 |
| 为什么不做基因型填补？ | 填补引入模型假设，本文要测的是数据本身的识别能力上限 |
| 会不会过拟合？ | 位点与阈值只在 Pilot 内确定并冻结，独立面板零重叠且不参与调参 |
| 和商业品种鉴定比准确率如何？ | 不作跨体系宣称；只报告本流程在自身评估框架内的表现 |
| 缺失当 0/0 有什么问题？ | 会把"没测到"当成"和参考一致"，系统性高估相似度 |
| 为什么用 IBS 不用别的距离？ | IBS 直接可解释、无需训练；另两种作为对照报告一致性 |
| 候选品种数量增加到几千个会怎样？ | 闭集难度上升；本文明确说明集合规模局限，开放集拒识是必要条件 |
| 数据量是清单声明还是实际下载？ | 明确区分清单声明值与实际落盘值，不混用 |
