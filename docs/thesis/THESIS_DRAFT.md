## 摘要

水稻品种真实性鉴定是种子质量控制与种质资源管理的核心环节。传统
SSR/InDel 标记鉴定通量有限，而常规全基因组重测序成本较高。本文探索
**超低深度全基因组重测序**（0.02×–1×）能否以极低的测序量完成品种识别。

方法上，本文以公共水稻 WGS 数据构建参考指纹库：先将 Pilot 样本
（{{RESULT: pilot 样本数}} 份）进行联合 SNP calling 与严格质控，筛得
嵌套的 500/1000/2000 个高信息量 SNP 位点作为指纹位点并**冻结**；
随后将同一批样本的高深度数据系统降采样至 1×、0.5×、0.2×、0.1×、
0.05×、0.02× 六个梯度，在冻结位点上做固定位点基因型判定，用
IBS 相似度做闭集识别，并统计 marker recall、基因型一致率、Top-1/Top-5
品种准确率。另外使用与 Pilot **零品种重叠**的独立样本集评估开放集拒识。

结果表明 {{RESULT: 核心结论}}。

**关键词**：水稻；品种识别；超低深度测序；SNP 指纹；IBS 相似度

## 1 引言

### 1.1 研究背景

水稻（*Oryza sativa* L.）是世界主要粮食作物之一，品种真实性与纯度直接关系到
种子质量监管、品种权保护与种质资源管理。随着审定品种数量快速增长，
同名异种、同种异名、以次充好等问题使**快速、低成本、可标准化的品种识别**
成为生产与监管环节的实际需求 {{CITE: 种子质量监管}}。

品种鉴定的分子手段经历了清晰的演进 {{CITE: 水稻分子标记鉴定}}：

| 阶段 | 代表标记 | 通量 | 主要局限 |
| --- | --- | --- | --- |
| 第一代 | RFLP、SSR | 数十个位点 | 通量低，跨实验室可比性差 |
| 第二代 | InDel、SNP 芯片 | 数百至数千位点 | 需专门设计芯片，难以扩展新样本 |
| 第三代 | 全基因组重测序 | 全基因组 | **测序成本高**，数据分析门槛高 |

全基因组重测序理论上可提供最丰富的变异信息，但其代价在于**深度**：
常规做法要求每个样本达到较高的覆盖倍数（通常为个位数到数十倍）
才能可靠地完成从头基因型判定 {{CITE: 水稻重测序深度要求}}。
对于"仅需区分品种"这一目标而言，这种深度要求是明显过量的——
品种间差异远大于个体内差异，识别本质上是**降维后的相似度匹配问题**，
而非全基因组变异发现。

由此产生本文的核心问题：**如果只为了识别品种，测序深度可以低到什么程度？**

### 1.2 研究现状

现有低深度测序研究的主流路径是**基因型填补**（genotype imputation）：
先以低深度数据得到稀疏的基因型，再利用大规模参考面板推断缺失位点，
之后在填补后的完整矩阵上做下游分析 {{CITE: 低深度填补方法}}。这条路线的
有效性高度依赖参考面板的规模与代表性——面板不够大时填补误差显著上升，
而构建大面板本身就是一项高昂的工作。

另一条思路是**直接使用低深度数据本身**，不做填补，只在少数高信息量位点上
做基因型判定与相似度比较。这条路线在作物品种识别上的系统报道仍然较少，
现有工作多集中于人类群体遗传学或畜禽育种场景。

本文选择第二条路线，动机来自三点：

1. 识别任务**不需要**全基因组完整基因型，只需要足够区分品种的判别性；
2. 免去填补即免去对大规模参考面板的依赖，流程更轻、更易复现；
3. 低深度下的不确定性可以**显式量化**（成功判型比例、比较位点数），
   从而给出"可信"与"不可信"的清晰边界，而不是输出一个无法评估置信度的匹配。

### 1.3 研究内容与创新点

1. 提出**两阶段**流程：先在 Pilot 高深度数据上做多样本联合 calling 与
   严格质控，筛选并**冻结**高信息量 SNP 位点集合；再在冻结位点上对
   超低深度数据做**固定位点判型**，避免低深度下的变异发现不确定性。
2. 用**技术重复**（同一批样本自身降采样）系统量化 1× 至 0.02× 六个深度梯度下
   识别能力的下限，并全程报告 marker recall 与比较位点数，
   使每个准确率数字都有可解释的分母。
3. 用与 Pilot **零品种重叠**的独立样本集评估**开放集拒识**，
   避免"闭集准确率"被误读为实用场景下的识别能力。
4. 提供可复现的命令行/Snakemake 流程，以及 SQLite 指纹库与 Web 原型，
   使方法不止停留在脚本层面。

需要明确的是，创新点不在于单个算法，而在于**面向超低深度场景的流程设计
与诚实的评估边界划分**（见 2.7 节）。

### 1.4 论文结构

- 第 2 章：材料与方法，说明数据来源、参考基因组、SNP 判定与识别流程、
  评估指标及其边界；
- 第 3 章：结果，按"数据质控 → SNP 检出 → 降采样深度 → recall →
  识别准确率 → 开放集拒识 → 原型系统"顺序呈现；
- 第 4 章：讨论，回应研究目标，并与已有路线比较，逐条陈述局限性；
- 第 5 章：结论。

#### 2.1.2 样本与品种名整理

对过滤后的 run 集合按样本聚合，得到 **32,564** 条候选样本记录
（`data/metadata/candidates/candidate_samples.tsv`），
经去重剔除 **1,326** 条重复样本（`duplicate_samples.tsv`），
并由 ENA/NCBI 元数据字段解析品种名，规范化后得到
**8,415** 个规范品种名（`variety_canonical.tsv`，另含 8,501 条别名映射
`variety_alias.tsv`）。

品种名来自样本 XML 的 `cultivar` 字段。该字段的填充情况直接影响
面板可用的规模，因此单独统计：在 **21,654** 个样本属性记录中，
`cultivar` 非空的有 **16,243** 条，即填充率 **75.0%**
（`data/metadata/candidates/sample_attrs.tsv`）。这意味着约四分之一的
公开样本无法直接获得品种标签，本文的面板只能在该子集中构建，
这是样本量的主要限制来源之一。

> **数据陷阱说明**：元数据中的品种名存在同名异种、拼写变体与

> 作绝对正确性声明**；附录 D 记录了人工复核过程。

### 2.4 联合 SNP calling 与位点筛选
- **关键方法说明**：正式 SNP 矩阵必须来自多样本联合 calling
  （或固定位点判型）；仅合并单样本变异 VCF 并把缺失当作
  `0/0` 会系统性高估一致性，本文明确不采用该做法
- 联合 calling：bcftools mpileup + call，参数 {{RESULT: calling 参数}}
- 质控过滤：{{RESULT: 过滤阈值}}
- 位点排序与筛选：按 {{CITE: 位点信息量指标}} 打分，取嵌套的
  500/1000/2000 位点集合
- **冻结原则**：位点集合只由 Pilot 决定，独立面板不参与任何
  位点选择或阈值调整

### 2.5 降采样模拟
- 用 samtools 按目标深度从高深度 BAM 中抽取读段，六个梯度
- 实际深度以 mosdepth 实测记录在
  `analysis/depth_downsampling_manifest.tsv`，不以目标值代替
- {{RESULT: 实际深度与目标深度偏差}}

### 2.6 低深度基因型判定与识别
- 在冻结位点上用 bcftools mpileup 限制到目标等位基因判型
- 剂量编码 0/1/2，缺失记为 `-1` 且**不做插补**
- 相似度：IBS 为主，Hamming、Jaccard 作为对照
- 识别时**始终同时报告比较位点数与比较率**；
  比较位点少于阈值（默认 50）时判为无法识别，而非给出偶然匹配
- 拒识阈值在 Pilot 内确定后冻结

### 2.7 评估指标
| 指标 | 定义 | 说明 |
| --- | --- | --- |
| marker recall | 低深度下成功判型的冻结位点比例 | 反映数据可用量 |
| 基因型一致率 | 与高深度参考一致且双方均调用成功的位点比例 | 仅在双方均调用时计算 |
| Top-1 品种准确率 | 最近邻品种等于真实品种的比例 | 闭集 |
| Top-5 品种准确率 | 真实品种出现在前 5 的比例 | 闭集 |
| 拒识率 / 接受率 | 开放集下的拒绝与接受比例 | 仅独立面板 |

> **评估边界**：Pilot 的六个深度是同一批样本降采样得到的**技术重复**，
> 因此只能支撑闭集 Top-1/Top-5 结论；零品种重叠的独立面板只能评估
> **开放集拒识**，不能用来声称"独立同品种识别准确率"。

## 4 讨论

### 4.1 主要发现
对照研究目标逐条回应。

### 4.2 与已有工作的比较
- 与基于填补的低深度分析路线相比，本文直接判型免去填补依赖
  {{CITE: 填补路线}}
- 与高深度重测序鉴定相比的成本–性能权衡

### 4.3 局限性

这一节必须写得比"结论"更诚实：超低深度识别最容易犯的错误，
是把技术重复上的表现当成真实场景下的能力。

**（1）技术重复 ≠ 独立重复。**
深度曲线上的每一个点，都是**同一份高深度数据自己降采样**得到的。
因此"1× 与 0.02× 的差异"反映的是**测序深度**单一因素的效应，
而不包含真实场景中的其他变异来源：不同批次/不同实验室的建库差异、
同品种不同个体间的残留杂合与体细胞突变、样本降解程度差异、
以及亚种内部的遗传背景差异。换言之，本文给出的是**深度效应的上界估计**，
真实场景下的表现不优于该曲线。

**（2）闭集识别偏乐观。**
闭集识别假设"待识别样本一定属于库中某个品种"。在这个假设下，
候选集合越大，最近邻越容易被偶然的相似样本抢占。本文的品种集合规模有限，
因此闭集 Top-1 数值**不能外推**到更大规模的实际品种库；
开放集拒识实验（3.6）正是为了部分弥补这一点。

**（3）面板规模与代表性问题。**
Pilot 与独立面板的样本量都很小，且受"品种名可解析"这一条件筛选
（即 2.1.2 节统计的 `cultivar` 字段填充率限制）。其后果是：面板中的品种未必代表
生产上主栽的品种结构，某些主栽品种可能因元数据缺失而完全不在库中。
样本量小还使估计的不确定性较大，本文报告的点估计应结合置信区间理解。

**（4）品种名元数据的可靠性。**
品种名来自公共数据库的样本注释，这些注释由**提交者**填写，
不受统一标准约束。已知风险包括：同名异种（不同单位用同一名称提交
不同材料）、同种异名（同一材料的拼写变体）、以及以代号/编号提交
而无正式品种名。本文通过规范化与别名映射做了归并，但**归并本身可能出错**，
且无法通过计算手段彻底验证。因此本文的"品种"应理解为
**元数据标签**，而非经过品种权或种子法意义确认的品种。

**（5）参考偏倚。**
本文以日本晴（IRGSP-1.0）为参考基因组，属粳稻背景。
籼稻、aus 等远缘样本与参考的序列差异更大，会导致：
比对率下降、读段堆积在保守区、以及固定位点判型时非参考等位基因
更难被可靠检出。这可能使**籼稻样本的有效数据量系统性低于粳稻样本**，
从而在亚种之间造成识别能力的差异。该效应的大小需由真实数据检验，
本文不预先假设其方向或幅度 {{CITE: 参考偏倚}}。

**（6）判型方法的适用边界。**
固定位点判型只在"位点已由 Pilot 冻结"的前提下成立。
若实际样本的变异图谱偏离 Pilot 所代表的群体（例如完全不同的亚种），
"未检出非参考等位基因"这一结果**既可能表示确实是参考基因型，
也可能表示数据不足**。本文用缺失编码（`-1`，不插补）与
比较位点数下限来区分这两种情况，但该区分依赖于阈值设定，
阈值本身存在误判风险。

**（7）评估指标的分母问题。**
基因型一致率只在"低深度与高深度双方均成功判型"的位点上计算。
这一条件会使一致率**系统性偏高**：因为低深度下容易判型的位点，
本身也倾向于信号较强、更可靠的位点。因此一致率必须与
marker recall 一并解读，单独报告一致率会误导。

**（8）未做的检测。**
本文不检测混合样本、不检测样本污染、不做品种内个体鉴别，
也不处理同一品种下的不同品系。这些在实际种子质量监管中是真实存在的需求，
但超出本文范围。

### 4.4 应用前景

基于上述边界，本文方法可能适用的场景与不适用场景应当分开陈述：

**可能适用**：
- 种质资源库内部的**去重与预筛**：在库内品种已知的前提下快速发现重复入库；
- 种子真实性**初筛**：对大量样本先做低成本排查，异常者再用高深度或
  官方标记复核；
- 大规模种质材料的**分组与结构探索**，用于后续精细化实验的设计。

**不适用**：
- 需要出具法律效力的品种鉴定结论（须使用标准方法并满足证据链要求）；
- 混合样本、种子批纯度检测（本文未做此类验证）；
- 库中完全没有的品种的"发现"——本文只能说"未匹配"，不能给出新结论。

**对实际部署的建议**：若将该方法用于生产，应先用**目标场景下采集的
独立样本**重新评估，而不是直接采用本文在公共数据技术重复上得到的数值。
