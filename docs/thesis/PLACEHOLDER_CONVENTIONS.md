# 服用说明：论文数据占位符约定

本文件定义 `docs/thesis/` 下论文骨架使用的占位符语法。

**核心纪律：骨架里不得出现任何看起来像真实结果的具体数字。**
所有需要由真实实验填充的位置一律写成占位符；只有已经确证的
方法学常量（如候选深度梯度、marker 数量档位）才允许写实际数值。

## 占位符语法

| 形式 | 含义 | 谁来填 |
| --- | --- | --- |
| `{{TODO: 说明}}` | 需要真实结果或文字 | 实验完成后由作者填写 |
| `{{RESULT: 指标名}}` | 具体数值，必须来自结果文件 | `07_identify.sh` 产出的 TSV |
| `{{FILE: 路径}}` | 需要插入的图或表 | `scripts/make_figures.py` 产出 |
| `{{CITE: 主题}}` | 需要补引文 | 文献调研 |

## 允许直接写死的数值

这些是**设计常量**，不是实验结果，可以出现在正文：

- 候选深度梯度：1×、0.5×、0.2×、0.1×、0.05×、0.02×
- marker 集合档位：500 / 1000 / 2000（嵌套）
- Pilot 样本数 30，独立面板 25（零品种重叠）
- 参考基因组 IRGSP-1.0（GCF_001433935.1）
- 相似度方法名：IBS（主）、Hamming、Jaccard

**注意"倍数"的判定边界**：`verify_thesis_placeholders.py` 只有在句中同时出现
"梯度 / 候选深度 / 降采样至 / 降至 / 预设 / 目标深度"等**设计措辞**时才放行
小于 1 的倍数；`实测深度`、`深度达到` 一律视为结果，必须用占位符。
含义不清的裸倍数（如"覆盖度为 0.3×"）按结果处理，宁可误报。

## 允许写死的第二类：数据整理与外部事实

以下**不是**实验结果，而是检索与整理阶段就已确定的事实，可以写具体数字，
**但必须在同一段内引用其来源文件**（`data/metadata/...` 或 `docs/...`）：

- ENA 检索各条件的命中数与过滤后 run 数
- 候选样本数、去重数、规范品种名数
- 元数据字段（如 `cultivar`）的填充数/填充率
- 面板样本数、品种数与清单声明的 FASTQ 字节总量
- 预检样本集（smoke1/smoke5）的构成与声明字节数

若同一句中还出现**本文自己测得的指标**（准确率、recall、实测深度、
Q30、比对率等），则该行一律判为失败——引用来源**不能**为编造的结果指标背书。

## 允许写死的第三类：已校验的生成型附录

附录 A（样本清单）这类**整表由脚本从清单生成**的文件，可以携带
每样本的声明值（accession、平台、读长、估计深度、声明文件大小）。
但守卫只在**同时满足**两个条件时放行其表格行：

1. 文件开头声明了生成它的脚本（`scripts/xxx.py` … 自动生成）；
2. 文件明确说明这些值是**声明值而非实测**（"不是实测/非实测/声明值"）。

并且——**叙述文字仍逐行检查**。因此"把编造的结果写进生成文件"不能得逞：
真实指标出现在表格行或正文中一律判失败。
这条边界由 `tests/test_thesis_placeholder_guard.py` 的 13 项测试锁定，
其中 4 项专门验证该豁免**无法被滥用**。

> 注意：文件头横幅在 Markdown 中可能换行，因此守卫对**文档头部**匹配，
> 而不是对单个物理行匹配——否则一个格式完全正确的文件会因为句子换行而被拒。

## 禁止事项

1. 不许写"准确率达到 XX%"而该数字并非来自真实结果文件。
2. 不许用示意图冒充实验曲线。
3. 不许在结论里出现未经计算的 ROC/AUC。
4. 独立面板的结论只能写开放集拒识，不得写成"同品种识别准确率"。
5. Pilot 的深度曲线必须标注为**技术重复的闭集评估**。

## 结果文件对照

论文里的每个数字都应当能追溯到下列文件之一：

| 结果文件 | 由谁产生 | 支撑论文哪部分 |
| --- | --- | --- |
| `analysis/identification/identification_by_depth.tsv` | `server/07_identify.sh` | 深度–准确率曲线、marker 数量影响 |
| `analysis/identification/<marker>/per_query.tsv` | `scripts/evaluate_identification.py` | 每样本明细、相似度分布 |
| `analysis/identification/<marker>/summary.json` | 同上 | 闭集声明与拒识阈值 |
| `markers/pilot.marker_ranking.tsv` | `scripts/select_snp_markers.py` | marker 筛选依据 |
| `markers/pilot.selection.json` | 同上 | 冻结参数与样本范围 |
| `qc/` 下 FastQC/MultiQC/mosdepth 输出 | `server/03_align.sh` 等 | 数据质量章节 |
| `joint/cohort.biallelic_snps.vcf.gz` | `server/04_joint_snp.sh` | SNP 检出章节 |
| `analysis/depth_downsampling_manifest.tsv` | `server/05_simulate.sh` | 降采样实际深度 |
