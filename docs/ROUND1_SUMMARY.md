## 〇、先说清楚这份报告没做什么

**本轮全部工作是"找数据、验数据、定样本"，没有跑任何基因组分析。**

- ❌ 没有下载任何 FASTQ/BAM
- ❌ 没有做比对、SNP calling、k-mer、CNV、SV
- ❌ 没有计算任何 marker、指纹、准确率
- ❌ 没有 ROC/AUC，没有 P 值

**因此本报告中没有任何"方法有效性"的结论**——那要等数据下载与分析之后。
本报告只回答一个问题：**这个项目有没有真实、可用的数据基础？**

## 十一、一个值得考虑的优化（写在最后）

Pilot + 测试集需 335 GiB，主要成本来自**下载了 20–40× 的完整数据**，
而实际实验最高只用 **1×**。

**ENA 的 FASTQ 支持 HTTP Range 请求**，理论上可只下载每条 run 的
一小部分读段（如 10–20%），**存储需求可降至 1/5 – 1/10**，
且仍足以覆盖 0.01×–1× 的全部模拟档位。

> **但这会改变"真值"的定义方式**（指纹基准本应从完整高深度数据建立），
> 需要**先做小规模验证**再决定是否采用。
> 本报告**不建议**在 Pilot 阶段就采用——先用完整数据跑通，把优化留到扩大规模时。
