# RiceVar-ID 本科毕业论文执行范围（现行规范 C）

> 生效日期：2026-09-20  
> 本文件记录用户最新确认的“本科毕设版”范围。历史规范 A/B 及既有产出继续保留，但后续实施以本文件为准。

## 1. 唯一必做主线

```text
真实公开水稻 WGS
→ 样本与品种名核验
→ FastQC / fastp
→ IRGSP-1.0 比对
→ SNP calling 与 QC
→ 500 / 1000 / 2000 SNP 指纹
→ 1 / 0.5 / 0.2 / 0.1 / 0.05 / 0.02× 随机降采样
→ Hamming + IBS（Jaccard 仅用于二元编码）
→ Top-1 / Top-5 + 开放集拒识
→ PCA / 热图 / 深度-准确率图
→ SQLite + Streamlit 原型
→ 本科论文与答辩
```

所有识别率、ROC/AUC、最低可用深度和 marker 数量结论都必须来自后续真实数据计算；当前不得预设答案。

## 2. 范围裁剪

### 必做

- 真实、可追溯的公开 WGS 数据；
- 20–30 个 Pilot 品种；
- SNP-only 主线；
- 六档深度、每档 3–5 个随机重复；
- 500 / 1000 / 2000 marker 比较；
- 简单可解释的 Hamming / IBS 相似度；
- 简单 Streamlit + SQLite 原型；
- 可复现脚本、图表和本科论文。

### 可选（仅在必做项完成后）

- k-mer 作为单一扩展实验；
- Snakemake 规范化；
- 同品种独立 run 的小规模补充验证。

### 不作为本科论文必做

CNV、SV、PAV、多 marker 融合、深度学习、复杂机器学习、混样检测、标签错误检测、500+ 样本、复杂群体遗传模型、PostgreSQL、FastAPI、Vue、Docker/Kubernetes、商业化数据库。

历史 CNV/k-mer/SV 文档与脚本仅作为研究档案，不得再写成现行必做路线，也不得用模拟结果冒充实验结果。

## 3. 现有数据如何使用

- `pilot_panel.tsv` 的 30 份样本作为现行 Pilot 候选集；
- `independent_test_panel.tsv` 的 25 份样本保持冻结，随机种子 20260920，不按结果重选；
- 两个面板品种零重叠，因此其角色必须区分：
  - Pilot 高深度指纹与其降采样重复：用于本科论文的闭集 Top-1/Top-5 技术验证；
  - 零重叠独立面板：用于开放集负样本/拒识测试，**不能**拿来计算“独立同品种 Top-1 命中率”；
  - 若后续补充同品种独立 run，可作为更强的生物学/跨批次验证，必须与降采样技术重复分开报告。

## 4. 防止数据泄漏

1. marker 候选与排序只使用 Pilot 高深度数据；
2. 500/1000/2000 marker 集在查看独立面板结果前冻结；
3. 降采样随机种子写入 manifest；
4. 独立面板不得参与 marker 选择或阈值调优；
5. 阈值在 Pilot 内通过留一/交叉验证校准，独立零重叠面板只作开放集验证；
6. 任何样本排除必须写入 `excluded_samples.tsv` 并给出 QC 原因。

## 5. 当前阶段门槛

目前仍未下载 FASTQ。进入下载前必须确认：

- 学校服务器调度器类型；
- 服务器可访问 ENA/EBI；
- 可用存储配额；
- CPU、内存；
- conda/mamba 或容器条件。

执行顺序固定为：服务器 probe → Pilot 1 份端到端 → Pilot 5 份 → 审查 QC 与流程 → Pilot 30 份 → 冻结的独立面板。未经 probe 不在本机下载大体积 FASTQ。
