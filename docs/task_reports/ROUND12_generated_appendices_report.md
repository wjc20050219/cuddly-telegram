## 二、附录 A：由脚本生成，而非手抄

**动机**：附录 A 是 55 行 × 13 列。手工抄写正是论文出现
"看起来很权威但错了一位"的典型来源。因此写
`scripts/build_appendix_samples.py`，从流水线**同一批** manifest 生成。

**关键设计——生成前强制校验 7 项不变量**，任一不满足即**不写文件**：

1. Pilot 恰为 30 份；2. 独立面板恰为 25 份；
3. 两面板品种交集为空（**本文最核心的科学不变量**）；
4. 面板内品种唯一；5. 全部为双端（PAIRED）；
6. 估计深度 ≥ 20×；7. run 号非空且 `panel_role` 唯一。

**并在生成器内复算正文引用的数字**：合计声明量必须等于正文所述的 334.71 GiB，
使正文与附录无法静默漂移。

**注入式验证**：对真实清单的副本注入 7 种破坏（品种重叠、面板内重复品种、
少一个样本、单端样本、12× 浅样本、空 run 号、错误 panel_role），
**7 项全部被检出**。另验证 `declared_bytes` 必须按 `;` 拆分——双端样本上
朴素 `int()` 会得到 0（这正是第十一轮发现 334.71 GiB 曾算成 0 的根因）。

**产物**：`docs/thesis/APPENDIX_A_samples.md`，113 行，
含 A.1 不变量汇总、A.2 Pilot 30 样本、A.3 独立面板 25 样本、
A.4 预检样本集、A.5 口径说明（`unknown` 亚种不推测、深度为声明值等）。

## 三、附录 B：版本号取自实测记录

原来 `{{CITE: 待补}}` 的位置现在有了实体。版本号**不是**凭印象写的，
而是逐条取自仓库内 `software_versions.txt`（检测日期 2026-09-15，2026-09-16 复核），
参数取自 `server/config.sh`、`03_align.sh`、`04_joint_snp.sh` 的**实际代码**。

写作过程中确认了三件必须在论文里说清、否则会误导的事：

1. **版本是在本机 WSL2 实测的，不是学校服务器**。附录明确写出
   "学校服务器上的最终运行环境可能不同"，并要求以服务器实测为准，
   **不得沿用本机版本冒充服务器版本**。
2. **fastp 使用默认参数**——没有自定义质量阈值/长度过滤/接头序列。
   这是一个有意的保守选择（覆盖面广、无需针对建库方式调参），
   代价是不如针对性调参精细。此事若不写明，读者会误以为做过调参。
3. **QC 阈值尚未确定，且这是设计而非疏漏**。`04_joint_snp.sh` 注释写明
   "其余 QC 在 Pilot 分布审查后执行"——MAF/缺失率/深度等位点级过滤
   将在看到 Pilot 真实分布后再定，避免用臆测阈值筛掉真实信号。

同时**拒绝声明任何校验和**：`reference_record.tsv` 在真实下载发生后才会产生，
截至写作时**尚未生成**，因此附录只描述该记录的 9 列结构与"完整 64 位摘要、
不截断"的不变量，不给任何数值（由测试强制：附录中不得出现 16–64 位十六进制串）。

## 四、守卫的两处新豁免，以及为什么它们不能被滥用

新增两份含大量数字的附录后，`verify_thesis_placeholders.py` 报出 55 处失败——
**全部是 `estimated_depth`**。这暴露一个真实的设计问题：这些是
**清单声明的估计值，不是本文的测量值**，但守卫无法表达。

**没有**采用"把深度加进白名单"的做法（那等于永久放行任何 ≤1 的倍数，
正是第十一轮修掉的漏洞的翻版）。改为新增**第三类：已校验的生成型附录**，
并要求**同时**满足两个条件才豁免表格行：

1. 文件头部声明了生成它的脚本；
2. 文件明确写出这些值是**声明值而非实测**。

并且**叙述文字仍逐行检查**。因此"把编造的结果塞进生成文件"不能得逞。

**过程中又发现一个真实缺陷**：横幅在 Markdown 里换行
（"…scripts/build_appendix_samples.py 从" 换行后才出现"自动生成"），
而正则要求同一物理行，导致**格式完全正确的文件被拒**。
已改为对**文档头部**匹配。这与第十一轮"逐行改逐段"是同类问题的第二次出现。

**滥用的证明**（4 项专门测试）：
- 在带完整横幅的文件里，表格中的假准确率 → **仍失败**；
- 同一文件正文中的假准确率 → **仍失败**；
- 无横幅文件的表格数字 → **失败**（无豁免）；
- 只有生成脚本名、没有"声明值"免责 → **失败**（半个横幅不够）。

至此守卫共四类判定：设计常量 / 数据整理事实（需溯源）/
已校验生成型附录（需横幅 + 免责）/ 结果指标（一律失败）。
