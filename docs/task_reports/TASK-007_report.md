## 三、在任务清单之外补充的三件事

任务清单只要求"建立四条路线"，但仅罗列流程不足以支撑后续实测。补充了：

### 3.1 四条硬约束（第 1 节）

所有路线都必须满足：

| 约束 | 含义 |
| --- | --- |
| **C1** | **必须在 ulcWGS（0.01×–1.00×）下工作** |
| C2 | 不做新湿实验 |
| C3 | 只传输特征矩阵（原始数据不出服务器） |
| C4 | 不预设最优标记类型 |

其中 **C1 是整个项目最锋利的约束**：它把"品种鉴定"这个常规问题变成了信息论问题——
在 ~0.05× 覆盖度下，基因组上还剩多少可判别信号？这正是本项目的核心科学问题。

### 3.2 统一比较框架（第 6 节）

**四条路线若不在同一条件下比较，结论无效。** 规定了：
- 相同样本、相同深度梯度（7 档）、相同重复数（≥5）、相同相似度（Jaccard）；
- 必报指标含 **ROC/AUC**（论文全文没有，是本项目核心增量）、Coverage–Recall、
  **计算成本**与**存储成本**；
- 三条公平性红线（不允许单独放宽某路线条件、不允许用自己的最优比别人的最差、
  不允许看结果后才分测试集）。

### 3.3 诚实的先验判断（第 5.4、9 节）

对每条路线标注"**已知**"与"**待验证假设**"，明确 6 条待验证假设（H1–H6），
避免把预期当作结论。

## 四、编制中的三个关键判断

### 4.1 ★ k-mer 路线的架构价值被低估

回顾 `benchmark_results.md` 的实测：**比对占单样本 CPU 的 69.8%**。
而 k-mer 路线 **不需要参考基因组、不需要比对**，直接对 FASTQ 计数——
**若成立可省掉这 69.8%**。对本项目（真正瓶颈是磁盘而非 CPU）这是最大杠杆。

已在文档中明确：这只说明它**成本最低**，**不代表准确率最高**——准确性仍须实测。

### 4.2 ★ SV 路线在 ulcWGS 下存在"定性困难"，不是调参能解决的

SV 检测依赖**跨越断点的 split reads** 或**方向异常的双端读段对**。
在 0.05× 下，一个 350 bp 的 SV 断点**可能一条读段都没覆盖**。

因此提出：本路线应以 **"PAV 优先"** 的形态进入比较——
复用公开泛基因组的 PAV 先验集，再用低深度做 presence/absence 判定，
而不是从零检测断点。这与路线 C 的"反筛"逻辑一致。

同时记录了**工具缺口**：标准 SV 工具（`delly`/`manta`）**尚未安装**，若推进需补装。

### 4.3 CNV 与 SV 的 deletion 重叠问题被澄清

两条路线的 deletion/duplication 是重叠的，区别在**检测机制**：

| | 路线 C | 路线 D |
| --- | --- | --- |
| 信号 | 窗口化**覆盖深度**（间接、聚合量） | **断点证据**（直接、稀疏） |
| 分辨率 | 窗口级（kb） | 断点级（bp） |
| 低深度可行性 | 较好 | **很困难** |

若不澄清，后续实测会出现"同一变异被两条路线重复计数"的问题。

## 五、k 值取舍的核心张力（第 3.3 节）

> **k 越大，品种间特异性越强，但在低深度下越难被观测到。**

| k | 特异性 | 对错误敏感 | 0.05× 下可获得性 |
| --- | --- | --- | --- |
| 21 | 低 | 低 | 高 |
| 31 | 中 | 中 | 中 |
| 51 | 高 | 高 | **低** |

存在一个最优 k，**必须实测**。这 6 个 k 值本身的曲线就是该路线的产出之一。
