### 2.1 每一步的理由

| 步骤 | 为什么 |
| --- | --- |
| 排除突变体 | EMS 突变体不是原品种，混入即标签错误（见 TASK-013 §三） |
| 仅短读平台 | 长读降采样的覆盖统计与短读完全不同，混入小规模 Pilot 会引入**平台偏倚**。平台间比较应作为独立实验后做 |
| **深度 20–50×（区间，不是"越深越好"）** | 目标实验最高只模拟到 **1×**，20× 与 200× 可用性相同，但后者存储开销是前者的 10 倍 |
| 每 BioSample 1 run | 避免技术重复造成权重失衡（最多者同一 BioSample 有 23 个 run） |
| 每品种 1 run | 避免单一品种主导 |

> ★ **深度区间的教训**：初版逻辑按深度**降序**取最深的，结果 55 份样本要 **1,662 GiB**，
> 中位深度 **170×**、最高 **673×**。改成区间后降到 **334.71 GiB**，中位 22–28×。
